# SISTEMA DE GERENCIAMENTO DE TAREFAS

### Organização prática e eficiente de atividades

---

# 🔥 INTRODUÇÃO
Sistema desenvolvido para facilitar a organização de tarefas e aumentar a produtividade no dia a dia.  
Com o **Sistema de Gerenciamento de Tarefas**, o usuário pode criar, editar, excluir e marcar atividades como concluídas, mantendo um controle claro e objetivo das suas demandas.

---

# ⚙️ PRÉ-REQUISITOS
O sistema foi desenvolvido para **uso individual**, com acesso controlado por autenticação.  
Apenas usuários cadastrados podem acessar e gerenciar suas tarefas, garantindo organização e segurança das informações.
